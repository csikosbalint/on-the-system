# product

This directory contains product management artefacts for the system.

## Contents

- **Vision & strategy** – the long-term product direction and goals
- **Roadmap** – planned features and milestones organised by quarter
- **Requirements** – user stories, epics, and acceptance criteria
- **Research** – user research findings, personas, and journey maps
- **Metrics** – KPIs, OKRs, and success definitions

## Workflow

1. New ideas are captured as **opportunity briefs** in `opportunities/`.
2. Prioritised items are elaborated into **user stories** in `requirements/`.
3. Delivered features are documented in the **changelog** (`CHANGELOG.md`).

## Conventions

- Write requirements from the user's perspective using the format:  
  *"As a [persona], I want [goal] so that [benefit]."*
- Every story must have clear, testable acceptance criteria before development begins.
- Link stories to relevant design artefacts in the `design/` directory.
